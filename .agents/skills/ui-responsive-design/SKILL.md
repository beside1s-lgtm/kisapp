# UI 반응형 디자인 및 렌더링 검증

## 레이아웃 원칙
- **헤더 & 설명:** 섹션 제목과 설명은 한 줄 표기를 원칙으로 가독 영역을 확보한다.
- **버튼 배치:** 하단 Flex/Grid 정렬. 공간 부족 시 텍스트 제거 후 아이콘만 남기거나 동적으로 축소하여 줄바꿈/겹침/이탈을 방지한다.
- **반응형:** Tailwind 브레이크포인트를 활용해 모바일/태블릿/데스크톱 대응.

## 다국어 및 Flexbox 수축 방지 패턴 (필수 점검)
- **텍스트 영역 최소 너비 확보:** `flex items-center` 또는 `flex-1` 자식 컨테이너에 단순 `min-w-0`만 단독 사용 시 flex shrink로 인해 폭이 극단적으로 좁아지는 현상을 방지하기 위해 `min-w-[180px]` 등 유의미한 최소 너비를 보장한다.
- **다국어 단어 분리 방지:** 베트남어/영어 등 다국어 텍스트가 한 글자씩 세로로 떨어지지 않도록 `break-words` 대신 `break-normal`을 기본 적용한다.
- **유연한 줄바꿈:** 부모 컨테이너가 좁아질 때 자식 요소가 화면 밖으로 이탈하지 않도록 `flex-wrap`을 적절히 결합한다.

## 검증 절차 (필수)
- 레이아웃 수정 후 반드시 `Puppeteer` 또는 `Chrome DevTools` MCP로 가상 브라우저 화면(스크린샷 또는 렌더링 상태)을 확인한 뒤 완료를 보고한다.
