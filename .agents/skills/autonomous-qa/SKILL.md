# QA 및 검증 워크플로우

1. **사전 점검:** 대규모 수정 전 `Git` MCP로 `git status`, `git diff`를 확인한다.
2. **공식 문서 참조:** 외부 라이브러리나 최신 프레임워크 API 적용 시 `Docs` MCP를 우선 조회하여 공식 문법을 확인한다.
3. **난해한 버그 분석:** 복잡한 에러나 설계 문제는 `Sequential Thinking` MCP로 3단계 이상 논리 분석 후 코드를 작성한다.
4. **자동 테스트:** 기능 구현/리팩토링 후 `TestSprite` MCP로 테스트 케이스를 생성하고 통과 여부를 검증한다.
5. **사후 점검:** 수정 완료 후 diff를 재검토하여 불필요한 변경 사항이 없는지 확인한다.
