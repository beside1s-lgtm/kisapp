# 학생 계정 일괄 등록 및 정합성 점검 워크플로우

## 1. 엑셀 업로드 양식 사전 검증
- 업로드 대상 엑셀 파일의 필수 열을 검증한다:
  - 필수 항목: `학년`, `반`, `번호`, `학생이름`, `학생 계정 이메일`
  - 선택 항목: `보호자 이름`, `보호자 연락처`
- 이메일 형식이 학교 도메인(`@kshcm.net`)과 일치하는지 확인한다.

## 2. Firestore 일괄 업로드 및 고아 데이터 방지
- 관리자 시스템 설정 → 사용자 → 학생 계정의 `일괄 등록` 기능을 통해 업로드를 실행한다.
- 데이터베이스에 저장 시 빈 문자열 또는 유효하지 않은 ID가 목적지/버스 등의 참조 필드로 들어가지 않도록 검증한다.

## 3. 학부모 PIN 설정 상태 정합성 확인
- 신규 등록된 학생 계정의 `hashedPin`은 기본값 `null`이어야 한다.
- 관리자 테이블에서 PIN 설정 상태가 '미설정' 배지로 올바르게 표기되는지 확인한다.
- 이미 PIN이 설정된 학생의 경우 초기화(RotateCcw) 버튼이 노출되는지 확인한다.

## 4. 최초 로그인 리다이렉션 검증
- 시스템 설정의 "학부모 PIN 인증 사용" 토글 상태를 확인한다:
  - **PIN 인증 ON**: 학생 계정으로 최초 로그인 시 `/parents/setup`으로 자동 리다이렉트되어 PIN 등록 및 서명 저장이 요구되는지 확인한다.
  - **PIN 인증 OFF**: PIN 번호 등록 절차가 생략되고 서명만 저장되면 즉시 학부모 메인 대시보드로 진입하는지 확인한다.
